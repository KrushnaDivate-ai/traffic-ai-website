# TrafficAI — Fixed Website Package

## Run locally
1. Extract this ZIP.
2. Open the extracted `TrafficAI_fixed` folder in VS Code.
3. Confirm `css/style.css` and `js/app.js` exist.
4. Open `index.html` with the VS Code Live Server extension, or double-click `index.html`.

This package includes the five HTML pages plus the missing CSS and JavaScript assets. The dashboard values are sample/demo values, not live traffic feeds.
